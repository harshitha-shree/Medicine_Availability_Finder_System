# Medicine Availability Finder System

## Project Overview

The Medicine Availability Finder System helps users quickly find the availability of medicines in nearby medical stores. The system allows pharmacies to update their medicine stock and enables customers to search for required medicines without visiting multiple stores.

---

## Problem Statement

People often spend a significant amount of time searching for medicines across different pharmacies. In emergency situations, locating a required medicine becomes difficult and time-consuming. This system provides a centralized platform to check medicine availability in various medical stores.

---

## Objectives

* To help users search for medicines easily.
* To display medicine availability in pharmacies.
* To maintain medicine stock information digitally.
* To reduce the time required to locate medicines.
* To provide accurate and updated stock information.

---

## Users

### 1. Admin

* Manage pharmacies.
* Manage medicines.
* View system reports.

### 2. Pharmacy Owner

* Add medicines.
* Update stock quantity.
* Manage medicine availability.

### 3. Customer

* Search medicines.
* View available pharmacies.
* Check medicine details.

## Modules

### 1. Login Module

* User authentication.
* Secure login for Admin and Pharmacy Owners.

### 2. Pharmacy Management Module

* Add pharmacy details.
* Update pharmacy information.

### 3. Medicine Management Module

* Add medicines.
* Edit medicine details.
* Delete medicines.

### 4. Stock Management Module

* Update medicine quantity.
* Track medicine availability.

### 5. Search Medicine Module

* Search medicine by name.
* Display available pharmacies.

### 6. Report Module

* View medicine records.
* Generate availability reports.
