**Medicine Availability Finder System**

**Project Overview**
The Medicine Availability Finder System is a web-based application designed to help users find the availability of medicines in nearby pharmacies. 
The system allows users to search for a medicine and view pharmacies where it is available. 
Pharmacy owners can update medicine stock details, ensuring that users receive accurate and up-to-date information.

**Problem Statement**
Finding a specific medicine can be difficult, especially during emergencies. 
Patients often spend considerable time visiting multiple pharmacies to check availability. 
This project provides a centralized platform where users can quickly search for medicines and identify pharmacies that have them in stock, reducing time and effort.
